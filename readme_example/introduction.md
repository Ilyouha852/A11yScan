# Введение

## Назначение проекта

**Attention Test for E-Scooter Safety** — это короткий тест, встроенный в приложение аренды электросамокатов. Он запускается прямо перед поездкой и проверяет, насколько пользователь сейчас внимателен и как быстро реагирует на простые стимулы.

Идея простая: прежде чем разблокировать самокат, система пытается понять, в каком состоянии находится человек именно в этот момент.

## Постановка задачи

Необходимо разработать систему, которая:

- запускает интерактивный тест перед началом поездки (не дольше 30 секунд);
- оценивает скорость реакции и базовые когнитивные показатели в реальном времени;
- учитывает внешние условия, такие как время суток и погода;
- на основе полученных данных даёт рекомендацию — стоит ли начинать поездку сейчас.

## Целевое назначение

Проект ориентирован на снижение числа аварий в сервисах аренды электросамокатов. За счёт быстрой проверки состояния пользователя система помогает отсеивать ситуации, когда человек объективно не готов к безопасной поездке — устал, отвлечён или реагирует слишком медленно.

> **Примечание:** система не является медицинским инструментом и не используется для диагностики заболеваний или состояний здоровья. Это прикладной скрининг, который оценивает внимательность пользователя здесь и сейчас.

## Область применения

Решение рассчитано на интеграцию в уже существующие платформы микромобильности и включает:

- мобильные приложения для пользователей (iOS и Android);
- серверную часть для расчёта результатов и хранения аналитики;
- API для обмена данными с системой аренды транспортных средств.
